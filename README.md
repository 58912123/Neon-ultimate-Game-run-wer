# Neon Ultimate Game runner

Welcome to NEON DASH, the infinite runner game!

In this game, you will run endlessly and try to reach whatever score your skill can get you. How long can you survive?

 Controls
Key / Button	Action
SPACE	Jump
UP ARROW	Jump
JUMP Button	Jump
RESTART Button	Restart game
 How to Play
Open the game in your web browser.
Click START GAME.
Jump over the incoming obstacles.
Avoid collisions to keep playing.
Try to beat your best score!
 Built With
HTML5 – Game structure and canvas
CSS3 – Styling, neon effects, and layout
JavaScript – Game mechanics, physics, and collision detection
Local Storage – Saving high scores
📥 How to Run
Download or clone this repository.
Open the project folder.
Open index.html in your browser.
Start playing!
🏆 High Scores

NEON DASH automatically saves your best score using your browser's Local Storage, so you can try to beat your record!
